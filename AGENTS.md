# AudioMeta Web frontend

Web interface to upload audio files, read and edit their metadata through the `audiometa-web-api` backend (powered by AudioMeta Python). See `README.md` for features and installation.

- Privacy: uploaded files and metadata are never stored permanently; do not add persistence, analytics or logging of file contents.
- Supported formats: MP3, FLAC, WAV (ID3v1, ID3v2, Vorbis, RIFF).
- The repository currently holds only the README; add validation commands here with the first code.
